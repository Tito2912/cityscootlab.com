# ISW50 : comment vérifier le code promo avant d’acheter (2026)

Les codes promo évoluent, et les promos ne se cumulent pas toujours. L’objectif de cette page n’est pas de “promettre” une remise, mais de vous donner une méthode pour **vérifier** en moins d’une minute.

<h2 id="how">Fonctionnement</h2>

ISW50 est souvent présenté comme “50 € offerts dès 500 €” pour les paniers éligibles. En pratique :

- un **seuil** de panier s’applique,
- certains produits peuvent être exclus,
- une promo en cours peut remplacer le code.

Donc : la source de vérité, c’est la dernière page avant paiement.

<h2 id="apply">Comment appliquer ISW50</h2>

1. Ajoutez la trottinette (et éventuellement des accessoires) au panier.
2. Allez au paiement.
3. Collez <code>ISW50</code> dans le champ coupon.
4. Appliquez et vérifiez le total.
5. Validez seulement si la remise est visible.

<h2 id="eligibility">Checklist d’éligibilité</h2>

- Mon panier dépasse le seuil requis.
- Le produit est éligible (certaines promos excluent des modèles/bundles).
- Aucune promo incompatible n’est déjà appliquée.
- La remise apparaît dans le récapitulatif final.

<h2 id="stacking">Cumul avec les promos (simple)</h2>

- Testez “avec code” et “sans code”.
- Gardez le meilleur total final.
- N’ajoutez des accessoires que si vous en avez réellement besoin (casque, antivol, chargeur).
