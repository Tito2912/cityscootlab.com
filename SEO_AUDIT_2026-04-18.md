# Audit SEO complet — cityscootlab.com (contenu + technique + CTR)

Date d’analyse : 2026-04-18  
Sources : exports Google Search Console ajoutés dans `cityscootlab.com-Performance-on-Search-2026-04-18/` (28 jours) et `cityscootlab.com-Performance-on-Search-2026-04-18 (1)/` (3 mois)

## 1) KPI (GSC) — où on en est

Périodes (d’après `Graphique.csv`) :
- **28 jours** : 2026-03-20 → 2026-04-16
- **3 mois** : 2026-01-17 → 2026-04-16

Synthèse :
- **3 mois** : 19 clics / 1 498 impressions — **CTR 1,27 %** — **position moyenne 14,02**
- **28 jours** : 8 clics / 624 impressions — **CTR 1,28 %** — **position moyenne 9,03**
- **28 jours précédents** (dans la fenêtre “3 mois”) : 7 clics / 495 impressions — **CTR 1,41 %** — **position moyenne 14,05**

Lecture :
- La **position moyenne s’améliore fortement** (≈14 → ≈9 sur les 28 derniers jours) : bon signal (indexation/ranking en progrès).
- Le **CTR ne suit pas** (reste ~1,3 %) : priorité = **optimiser snippets + intent** sur les pages déjà en page 1.

## 2) Opportunités CTR (GSC-first)

Pages avec impressions significatives et **0 clic** malgré une bonne position :
- `/isinwheel-s9-pro-review-2026` — 137 impr — pos ~6,1 — 0 clic
- `/isinwheel-coupon-isw50-2026` — 25 impr — pos ~7,6 — 0 clic
- `/de/isinwheel-commuter-guide-2025` — 24 impr — pos ~6,7 — 0 clic
- `/fr/isinwheel-commuter-guide-2025` — 15 impr — pos ~8,0 — 0 clic

Note : l’URL **legacy** `/blog-1` apparaît encore dans les exports (impressions) mais elle **redirige en 301** vers `/isinwheel-commuter-guide-2025`. L’objectif est que Google consolide progressivement sur l’URL canonique.

### Requêtes “proches du clic” (28 jours)

Requêtes qui rankent déjà (≤10) mais ne cliquent pas encore :
- `isinwheels` — 7 impr — pos ~5,1 — 0 clic
- `isinwheel s9 pro review` — 3 impr — pos ~5,7 — 0 clic
- `isinwheel gt2 reviews` — 2 impr — pos ~7,5 — 0 clic

Lecture :
- Certaines requêtes “marque” (ex : `isinwheels`) ont un CTR structurellement faible (les utilisateurs cherchent souvent le site officiel).
- Les requêtes **review** / **coupon** sont, elles, de très bonnes cibles : le CTR doit monter via promesse + précision (année, bénéfice, chiffres, “qui doit éviter”, etc.).

## 3) Segments (pays / appareils) — où le CTR décroche

### Pays (28 jours)

Points saillants :
- **États-Unis** : 230 impr — 1 clic — **CTR 0,43 %** — pos ~9,25 (CTR très faible malgré une bonne position)
- **France** : 137 impr — 5 clics — CTR 3,65 % — pos ~11,93
- **Allemagne** : 53 impr — 0 clic — pos ~7,43 (snippet à travailler sur pages DE visibles)

Hypothèses actionnables (US) :
- snippets trop “EU/€” pour un public US (à tester en neutralisant la devise dans titles/descriptions EN),
- concurrence très forte (officiel, shopping, marketplaces) → nécessité d’une promesse “review / verdict / pros-cons” plus claire.

### Appareils (28 jours)

- **Ordinateur** : 398 impr — 4 clics — CTR 1,01 % — pos ~9,6  
- **Mobile** : 225 impr — 4 clics — CTR 1,78 % — pos ~7,96

Piste : renforcer la “lisibilité SERP” desktop (titres plus courts, bénéfice + preuve rapide, descriptions moins génériques).

## 4) Audit technique (résumé)

Constats (audit local sur `out/`) :
- Pages exportées : **70** pages HTML.
- Titres/descriptions/canonicals : globalement complets (doublons uniquement sur pages 404).
- Hreflang : présent sur les pages via `alternates`, mais le **sitemap.xml ne portait pas** les alternates (opportunité).
- URLs locales `/fr`, `/de`, `/es` existent en export (fichiers `.html`) mais la stratégie 301 → `/fr/`, `/de/`, `/es/` est correcte.
- `https://cityscootlab.com/sitemaps/sitemap-en.xml` répond **404** (vérifié le 2026-04-18). Si ces URLs ont été soumises dans GSC, les retirer et ne garder que `/sitemap.xml`.

## 5) Audit contenu (résumé)

Forces :
- Structure claire (jump links, “quick answer”, FAQ, internal linking).
- Pages “hub” (deals/coupon/guide) cohérentes pour capter des intentions “transactionnelles + informationnelles”.

Faiblesses / leviers impressions :
- Pages review parfois **courtes** vs SERP concurrents → ajouter plus de valeur unique (table specs + “qui doit acheter/éviter”, sections “range/hills/weight”, notes d’usage réel, photos/mesures si disponibles).
- Mettre en avant la **fraîcheur 2026** quand c’est réellement mis à jour (titre + H1 + date visible).

## 6) Plan d’action priorisé (impressions + CTR)

P0 (impact rapide, 7–14 jours) :
- Réécrire titles/descriptions des pages à fort potentiel (pos 5–9, CTR faible).
- Harmoniser “année + bénéfice + verdict” et éviter les titres trop longs/tronqués.
- Ajouter `hreflang` dans le sitemap + `x-default` (international SEO).

P1 (impact ranking + impressions, 2–4 semaines) :
- Enrichir les pages review (sections manquantes + preuves + comparaisons).
- Créer 2–4 contenus “long-tail” (ex : “discount code / promo code” par pays, “S9 Pro vs alternatives”, “best under 600” sans devise).

P2 (continu) :
- Maillage interne systématique : chaque page doit pousser vers 2–3 “money pages” (coupon/deals/reviews) + 1 hub.
- Mettre à jour trimestriellement “2026” (titres + dates + sections).
